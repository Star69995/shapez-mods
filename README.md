# Star's shapez mods

Mods for [shapez](https://shapez.io/) made by **Star** ([Star69995](https://github.com/Star69995)).

## My mods

| Mod | What it does for you | mod.io |
|---|---|---|
| [Multi-Edit Buildings](multi-edit-buildings/) | Change the settings of many buildings at once - re-channel a copied blueprint's teleporters, set or sequence-fill dozens of signal generators, set storage limits - instead of clicking each one | [download](https://mod.io/g/shapez/m/multi-edit-buildings) |
| [Status Display](status-display/) | A live on-screen dashboard of the wire values you care about (storage full, current goal, colors, shapes), visible from anywhere on the map | [download](https://mod.io/g/shapez/m/status-display) |
| [Performance Monitor](perf-monitor/) | A plain-language panel showing how heavy your factory is, how many more buildings it can take, and a one-key test that shows what slows the game most (English and Hebrew) | [download](https://mod.io/g/shapez/m/performance-monitor) |
| [Full-Speed Ejectors](full-speed-ejectors/) | Removes the hidden 15 items/s output cap at 30 ticks/s: belts fed by buildings carry as much as the belt allows | [download](https://mod.io/g/shapez/m/full-speed-ejectors) |
| [Factory Compressor](factory-compressor/) | Turn a huge factory into one building that runs a light model of it, so the game stops simulating every belt and machine (experimental - back up your saves) | [download](https://mod.io/g/shapez/m/factory-compressor) |
| [Compact Saves](compact-saves/) | Add-on for Factory Compressor: much faster saving and loading with many compressed factories | [download](https://mod.io/g/shapez/m/compact-saves) |
| [Shape Vault](shape-vault/) | A second storage next to the Hub, with its own extractors, a level sensor for the wires layer and a statistics window | [download](https://mod.io/g/shapez/m/shape-vault) |
| [Hide Empty Stored Shapes](hide-empty-stored-shapes/) | Removes zero-stock shapes from the Statistics list and the savegame so they stop piling up | [download](https://mod.io/g/shapez/m/hide-empty-stored-shapes) |
| [BalancerVariants - Industries Compat](balancer-variants-industries-compat/) | Brings back the big 3x1-10x1 balancers when you play with Shapez Industries | [download](https://mod.io/g/shapez/m/balancer-variants-industries-compat) |

## Installation

Download the mod's `.js` file, put it in your shapez.io `mods` folder (on Windows: `%APPDATA%\shapez.io\mods`) and restart the game.
